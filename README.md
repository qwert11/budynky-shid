# Жильё под удалёнку · восток · Киевщина, Днепропетровщина, Кировоградщина

Восточный двойник каталога запада ([budynky-zahid](https://github.com/qwert11/budynky-zahid),
сайт — qwert11.github.io/budynky-zahid). Код — копия его пайплайна от 21.10.2026 с заменёнными
справочниками областей; правила отбора, индексы, карта и проверки те же. Подробное описание
каждого правила и истории решений — в README западного каталога; здесь — только то, чем восток
отличается.

Сайт: **https://qwert11.github.io/budynky-shid/**

## Задание покупателя (21.10.2026, дословно)

«у меня собраны города запада … сделай похожую карту qwert11.github.io/budynky-shid — добавь пока
что сюда киевскую и днепропетровскую и кировоградскую область … пока дома должны попасть 20–30 и
30–35 тыс долларов».

## Все источники и дома от 40 м² в полосе $20–30k (22.10.2026)

Покупатель, дословно: «почему у тебя из других источников нихуя нет … делай давай всё, и через
браузер собирай, если блочат». Повод — его рилс: дом в Малой Виске за $22 500, 3 комнаты, на
OLX выложен дважды, но площадь **41 м²**, и порог «дом от 65 м²» его отсекал вместе с 1 099
домами из 2 332.

- **Порог площади** — `houseAreaMin()` в `lib9.js`: в полосе $20–30k дом от 40 м², в $30–35k —
  от 65 м². Применяется во всех сборщиках и в `units9.js`. Новые 385 домов OLX проверены по фото
  (305 ok, 80 no). Дом из рилса стоит в каталоге (ID11hOhv), его второе объявление — дубль.
- **Rieltor.ua** — curl получает 429 уже на четвёртом запросе, поэтому страницы берутся
  браузером `br` (`scripts/lib-br9.js`, своя вкладка). Поиск по области: `/houses-sale/<Область>-r<id>/`
  (Київська r111, Дніпропетровська r119, Кіровоградська r114); неизвестный адрес области сайт
  молча подменяет Львовом. Цена в грн тремя полосами.
- **Метраж** — слаги областей `ko` / `dnp` / `kir`. Точка — село из адреса карточки через
  Nominatim в контуре области (а не центр облцентра). Зеркала OLX выбрасываются, как на западе.
- **DOM.RIA** — добран дешёвыми домами 40–65 м².
- **Телеграм** — каналы той же серии, что на западе: `domua_`, `vlasniki_`, `realtyin_` для
  kyiv / dnipro / kropyvnytskyi; история выбрана целиком (`TG_PAGES=60`). Каналы в основном про
  квартиры: домов в бюджете с ценой — 7.
- **Flatfy** — 3 753 карточки, все зеркала OLX, DOM.RIA, Rieltor и ЛУНа; своих лотов нет.
- **ЛУН** не собирается: на странице Днепра все 32 карточки — из Rieltor.ua, который теперь
  собирается напрямую. Его старый сборщик ссылался на модуль из удалённого scratchpad.
- **Facebook Marketplace** — поиск снова упёрся в «Rate limit exceeded» и успел пройти только
  10 точек у Киева из 74; карточки (другой запрос) открылись. Темп сборщика замедлен вдвое.
- Источники без единого лота на странице не показываются (`SRC_HAVE` в `render9.js`).
- **Facebook Reels** (`scripts/fb9-reels.js` → `fb9-reels-parse.js` → `data/fbr9-candidates.json`).
  Покупатель: «нахуй ты ищешь на маркетплейсе — facebook.com/reel/ тут дохуя есть, или рекомендации
  бери». Лента рекомендаций листается в браузере `br`; подпись, автор и два кадра видео. Только
  с ценой — в подписи или в репликах автора в комментариях (`fb9-reels-comments.js`), без цены —
  мимо (правило покупателя). Место — село или город из подписи. Лента учится на времени просмотра:
  на домах сборщик стоит 40–60 с, остальное листает за 2–3 с, при застревании перезапускается с
  последнего найденного дома (со старта шла по кругу). Первые 512 рилсов: про продажу дома 35,
  в каталог — 4 (16 без цены, 10 вне бюджета). Кадр на миниатюру — `data/fbr9-pick.json`.

## Чем отличается от запада

- **Области:** Київська (`kyi`), Дніпропетровська (`dnp`), Кіровоградська (`kir`). OLX region_id
  25 / 21 / 7, DOM.RIA state_id 10 / 11 / 16. Справочники — `lib9.js` (`CITIES9`, `REGION2SLUG`,
  `SLUG2LABEL`), `olx-harvest9.js` (`REGIONS`), `units9.js` (`OBL_ZONE`, `ZONE_REGION`),
  `lib-fb9.js` (`OBL_RE`, `ZONE`, `REGION_UA`), `fetch-shapes9.js`, `industry.js`, `domria9.js`,
  `render9.js` (`CITY_RU`, `STRIKE_RU`), `strikes.js` (`STEM`, `OBL`).
- **Киев-город в каталог не входит.** В контуре Киевщины он дыркой (отдельная административная
  единица), а `gate()` в `units9.js` пропускает только точки внутри одной из трёх областей. Как
  опорный город для правила «до 10 км» Киев при этом работает.
- **Соседние города у границ** (Черкаси, Кременчук, Умань, Сміла, Ніжин) стоят в `CITIES9`: дом
  на Кировоградщине в 5 км от Кременчуга — «у города».
- **Бюджет — только дома $20–35 тыс.**, две полосы `PRICE_BANDS`: $20–30k и $30–35k, у каждой своя
  сотня на область в каждом источнике. Квартиры не собираются (`olx9-flats.json` пустой).
- **Источники:** OLX, DOM.RIA (поиск по области целиком, без `city_id`), Facebook Marketplace.
  ЛУН, Телеграм, Rieltor (бан IP), Метраж, Flatfy для востока не заведены.
- **Ключи браузера — `bhe:*`**, а не `bh:*`: оба сайта живут на одном домене qwert11.github.io и
  иначе делили бы избранное, корзину и фильтры.
- **Проекция карты** — та же «старая» система координат, границы вида `LON0..LON1`, `LAT0..LAT1` в
  `clustermap9.html` под восток; слой населённости (`{{HEAT}}`) строится из `CITIES9`, контуры
  крупных городов — `scripts/fetch-cityshapes9.js`.
- **Слой «куда летело»** — тот же канал «Николаевский Ванёк», свой словарь основ. Ловушки:
  «Покров» ≠ «Покровск» Донецкой области; «Васильков» ≠ «Васильковка»; «Днепр» — и город, и река
  (обороты «вдоль/по/через Днепр…» не считаются); «Шахтёрск», «Зеленодольск», «Благовещенск»
  есть в России и на Донбассе — поэтому Шахтарське ищется только как Першотравенськ, Зеленодольск
  не ищется вовсе; Самар — по старому имени Новомосковск. **Артиллерию и FPV канал не ведёт**:
  у Никополя, Марганца и Покрова цифра на карте — только ракеты и «шахеды».
- `strikes-fetch.js` докачивает только страницы выше прошлого верхнего id (кэш `strikes-raw`
  скопирован с запада), а не перекачивает всю историю по сдвинутой сетке.

## Пересборка

```bash
node scripts/olx-harvest9.js houses 20000 35000   # OLX, бисекция цены (потолок выдачи 1000)
node scripts/geocode9.js                          # центры сёл, Nominatim
node scripts/domria9.js house 20000 35000         # DOM.RIA по областям
node scripts/fb9-market.js all 30                 # Marketplace (браузер br, вход покупателя; часы)
node scripts/fb9-market-parse.js                  # → data/fbm9-candidates.json, фото — глазами
node scripts/fetch-shapes9.js && node scripts/fetch-cityshapes9.js && node scripts/industry.js
node scripts/strikes-fetch.js && node scripts/strikes.js
node scripts/addr9.js                             # улицы из текстов → точные метки
node scripts/units9.js                            # отбор, топ-100 на полосу → units9.json, vet-need.json
node scripts/vet-grid.js 400                      # сетки фотопроверки домов OLX; вердикты — vet-apply.js
node scripts/units9.js && node scripts/thumbs9.js && node scripts/render9.js
node scripts/check-dead.mjs                       # снятые → dead.json, затем units9 + render9
```

Долгие сборы запускать отдельным процессом (`Start-Process`, см. `_tmp/*.ps1`), логи — в `_tmp/`.
